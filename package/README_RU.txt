EyeContact v1.0 — коррекция взгляда в камеру для Premiere Pro
==============================================================

Эффект «переводит» взгляд человека в камеру, когда он смотрит в сценарий или
чуть мимо объектива. Работает на нейросети NVIDIA Maxine (Gaze Redirection).


ТРЕБОВАНИЯ
----------
* Windows 10/11, видеокарта NVIDIA RTX 20, 30, 40 или 50 серии, свежий драйвер.
* Premiere Pro 2025/2026 (работает и в After Effects).
* NVIDIA AR SDK runtime v0.8.7 — бесплатный, установщик сам его предложит.


УСТАНОВКА
---------
1. Распакуйте архив в любую папку.
2. Запустите Install.bat и разрешите права администратора.
3. Установщик проверит видеокарту. Если runtime NVIDIA ещё не стоит, он предложит
   скачать его (около 1,3 ГБ) с сайта NVIDIA и запустит установщик.
   Windows может показать «неизвестный издатель» — NVIDIA подписала этот пакет
   своим внутренним сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».
4. Закройте Premiere, если попросит, — плагин скопируется сам.

Если хотите поставить runtime вручную: www.nvidia.com/broadcast-sdk-resources →
AR SDK v0.8.7, файл под вашу серию (RTX 20 = Turing, 30 = Ampere, 40 = Ada, 50 = Blackwell).


КАК ПОЛЬЗОВАТЬСЯ
----------------
Effects → Video Effects → Maxine → EyeContact, перетащить на клип.
На первом кадре Premiere может задуматься на секунду — загружается модель.

Параметры:
* Strength — сила эффекта, 0–100 %.
* Keep original color — ВКЛ по умолчанию. Сохраняет родной цвет глаз:
  без него нейросеть может «перекрасить» радужку (особенно на log/плоской картинке).
* Temporal smoothing — сглаживание между кадрами, ВКЛ по умолчанию.
* Eye size sensitivity — размер перерисовываемой области глаз (2–5).
* Natural look-away — изредка отводит взгляд, чтобы не было «сверлящего» эффекта.
* Angle thresholds — при каких углах головы и взгляда эффект работает
  и с какого угла отключается (если человек сильно отвернулся).

Советы:
* Лучше всего работает на «говорящей голове», лицо крупно, человек смотрит
  недалеко от камеры (суфлёр, сценарий рядом с объективом).
* Сравнивайте результат кнопкой fx в Effect Controls.
* Корректируется одно лицо в кадре.
* Плагин меняет только пиксели глаз — остальной кадр остаётся бит-в-бит.


ЕСЛИ НЕ РАБОТАЕТ
----------------
* Эффекта нет в списке — перезапустите Premiere с зажатым Shift (пересканирует плагины).
* Эффект есть, но ничего не меняется — откройте лог: в адресной строке Проводника
  введите %TEMP% и найдите файл EyeContact.log. Там написано, что пошло не так.
  Пришлите этот файл тому, кто дал вам плагин.


УДАЛЕНИЕ
--------
Запустите Uninstall.bat. Runtime NVIDIA удаляется отдельно через
«Установленные приложения» Windows (NVIDIA AR SDK).
